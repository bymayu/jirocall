# JIRO CALL GENERATOR

ラーメン二郎における独特の注文システム「コール」をシミュレーションし、最適な呪文を生成するためのWebアプリです。

## 概要
ラーメン二郎の店舗にて「ニンニク入れますか？」と聞かれた際、緊張してコールを間違えてしまう初心者の不安を解消するために開発しました。
各項目の好みを直感的に選択するだけで、店員さんに伝えるべき正確なフレーズを表示します。

## 主な機能
* **コール自動生成**: ニンニク、ヤサイ、アブラ、カラメの組み合わせを最適化して出力します。
* **二郎専用ロジック**: 「全マシ」判定や、ニンニクの有無による独特の言い回しに対応しています。
* **麺の量に関する警告**: 初心者が最も失敗しやすい「麺少なめ・半分」の申告タイミングを明記しています。
* **モバイルファースト**: 列に並んでいる最中に片手で操作しやすいUI設計。

## 使い方
1. 自分の好みの量を各項目から選択します。
2. 最下部の黒いセクションに表示された黄色い文字を確認します。
3. 店員さんの問いかけに合わせて、その文字をそのまま読み上げます。

## 免責事項
* 本ツールは一般的な二郎のルールに基づいたコールを生成しますが、店舗独自のルールや限定トッピングがある場合はそちらを優先してください。
* **店内でのスマートフォン使用について**: スマートフォンに夢中になりすぎると、ロットを乱したり店員さんに注意されたりする可能性があります。コールを確認した後は速やかにしまい、食事に集中することを推奨します。
* 完食できる量での注文を強く推奨します。
